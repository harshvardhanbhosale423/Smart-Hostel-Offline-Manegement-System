Smart Hostel Full GUI App
=========================

Login:
- Username: admin
- Password: admin123

How to build:
1. Run build_app.bat
2. It creates SmartHostel.exe

How to run:
1. Run SmartHostel.exe directly
or
2. Run run_app.bat

How to install:
1. Run installer.bat
2. It creates a Desktop shortcut

Features:
- Admin Login
- Student Registration
- Student Entry
- Student Exit
- Search Student by ID and Name
- View All Students
- View Entry History
- View Exit History
- Daily Report
- Monthly Report
- Late Entry Report
- Visitor Management
- Update Student Details
- Delete Student
- Statistics
- Export Report to TXT
- File handling with students.txt, entrylog.txt, exitlog.txt, visitors.txt
